# Reproduction programs

| Entry point | Purpose |
| --- | --- |
| `rebuild_tables.py` | Rebuild tables |
| `reproduce_figures.py` | Replot figures |
| `prepare_case.py --list` | List simulation cases |
| `postprocess/` | Process new trajectories |
| `force_constants/` | Prepare and process force-constant calculations |

Run commands from the repository root. Generated files go to `outputs/`.
See [running instructions](../docs/reproduction.md) and [data definitions](../docs/data_dictionary.md).
